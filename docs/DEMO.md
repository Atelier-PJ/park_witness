# 시연 순서

모든 차량과 사고는 가상 시나리오입니다. 실제 사고를 재현하지 않습니다. 사전 동의한 테스트 파일 또는 직접 만든 이미지로 시연하세요.

1. README의 seed-demo로 세 계정을 만듭니다. API와 웹을 실행합니다.
2. requester 로그인 → DEMO-PARK/B2/B, 최근 1시간~30분 전, 피해 내용 등록.
3. 후보 찾기 → 익명 1명 확인. B3의 other는 제외됩니다. 같은 버튼을 재실행해 중복 요청이 늘지 않는 것을 확인합니다.
4. witness 로그인 → 받은 요청 → 확인 예정 → 공유 검토 → 모의 자료 파일 선택·등록.
5. requester로 전환 → 승인 전 자료가 없는 것을 확인합니다.
6. witness로 전환 → 공유본 미리보기 → 수신자·목적 체크 → 공유 승인.
7. requester → 승인 자료 받기. 해시·모의 자료 표기를 확인합니다.
8. witness → 승인 철회 → requester가 더 이상 받을 수 없는 것을 확인합니다.
9. 새 사건으로 영상 없음/거절을 시연합니다. 하루 등록 제한은 5건입니다.
10. 차량 앱 demoDebug를 실행하면 requester 시연 계정으로 자동 로그인됩니다. 홈의 사고·요청·주차 요약과 주변 차량 영상 미리보기를 확인합니다. 사고 확인 화면의 기스 사진은 안내용 예시이며 실제 피해 사진으로 저장되지 않습니다.
11. 차량 앱에서 주차 참여를 수동 등록·철회합니다. demo의 P 상태가 실제 차량 신호가 아님을 표시합니다. 실제 피해 사진과 공유 파일 등록·승인은 모바일 웹에서 시연합니다.

화면에서 자료를 다시 확인하려면 계정 전환 후 새로고침합니다. 차량 전원 종료 후 상시 녹화·푸시 수신·영상 확보를 시연한 것처럼 설명하지 않습니다. Pleos 빌드의 실제 주차 신호 검증은 별도입니다.
