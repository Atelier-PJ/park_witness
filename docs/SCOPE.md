## 공식 기술 자료

2026-11-12에 공식 문서의 기준을 확인했습니다. 기존 Park on Wheels의 실행 결과를 새 앱의 실행 결과로 간주하지 않습니다.

- [주행 규제 가이드](https://document.pleos.ai/docs/pleos-only/vehicle-app-developer-guide/driving-restriction-development-guide): CarUxRestrictions와 변경 콜백을 기준으로 기능을 제한합니다. 본 MVP는 보수적으로 모든 제한에서 상세 입력을 차단합니다.
- [Vehicle SDK Sample App](https://document.pleos.ai/docs/pleos-only/tutorial/vehicle-sdk-sample-app): Vehicle SDK 2.3.2, Vehicle Service 2.3.22, 전용 AVD 환경을 안내합니다. 초기화 성공만으로 개별 기능 지원을 판단하지 않습니다.

## 후속 검증

1. 허가된 Pleos AVD에서 권한·P/비P·UX 변경·연결 해제·오래된 콜백·재접속을 검증하고 화면 증거를 추가합니다.
2. 실제 시설의 인접표와 확인된 동의 참여자를 연결합니다. 후보 수를 영상 수로 표시하지 않습니다.
3. 본인·차량 확인, 운영 신고 처리, 외부 메일/푸시, 객체 저장소, 로그인/업로드 남용 방어, 데이터 마이그레이션을 구성합니다.
4. 제공 근거·제3자 권리·마스킹 절차·보관 정책을 검토한 후 제한된 파일럿을 진행합니다.
